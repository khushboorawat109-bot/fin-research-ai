# Final demo script (~8 minutes)
1. **Intro (30s)** — problem + architecture diagram (`docs/ARCHITECTURE.md`).
2. **Session + seed data (1m)** — create session "Indian IT Peers"; show the 3-4 seed companies attached.
3. **Upload pipeline (1.5m)** — upload one extra PDF; watch Document -> Extraction -> Red Flag progress.
4. **Analysis tab (1.5m)** — open red flags (expand one: quote + page); show metrics with verified badges
   and a computed ratio; point out the unverified-row handling.
5. **Comparison (1m)** — table + ratio leaders + commentary.
6. **Research chat (2m)** — ask: "Compare operating margin of A and B and explain the change vs last year";
   show plan, cited answer, sources. Then ask something absent ("What is the CEO's favourite colour?") to
   show "Not found in the provided documents."
7. **Report (1m)** — generate PDF, download, scroll all sections.
8. **Wrap-up (30s)** — grounding safeguards, test results (accuracy %), limitations/future work.
